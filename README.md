# Custom Ad Blocker Browser Extension

A private, custom Google Chrome ad blocker built using Manifest V3 and the declarativeNetRequest API. This extension supports Regular and Super blocking modes, a dynamic website exclusion whitelist, and a customizable theme switcher (Light, Dark, and System modes).

## Features
* **Dual Blocking Modes:** Instantly toggle between Regular and Super (Aggressive) network ad filtering.
* **Dynamic Whitelist:** Exclude specific website domains directly from the popup menu interface.
* **Theme Customization:** Seamlessly shift the popup interface between Light Mode, Dark Mode, or match your local system preference.

## Installation (For Personal Private Use Only)
1. Download or clone this folder to your local machine privately.
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** using the toggle switch in the top-right corner.
4. Click **Load unpacked** in the top-left corner.
5. Select the extension directory containing the `manifest.json` file.
